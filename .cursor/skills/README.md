# Workshop agent skills

Install by copying each folder into your agent skills directory, e.g.:

- Cursor / custom: `~/.agents/skills/<skill-name>/`
- Claude Code: `~/.claude/skills/<skill-name>/`

Each skill is a folder containing `SKILL.md` (and optional support files).

## Pipeline (spine)

1. `grill-me` / `grill-with-docs`
2. `to-prd`
3. `to-expo`
4. `start-ticket` → build → `ship-ticket`

Setup helpers: `setup-matt-pocock-skills`, `setup-git-flow`

## Build-time modes

- `honest-thinking-partner`
- `nextjs-senior` (includes `tools/`)
- `explain-diff` (HTML) / `explain-diff-notion` (Notion)

Source for explain-diff: https://gist.github.com/geoffreylitt/a29df1b5f9865506e8952488eac3d524
